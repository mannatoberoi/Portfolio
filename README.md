## 🚀 Getting Started

### Prerequisites
- A modern web browser
- Basic knowledge of HTML, CSS, and JavaScript

### Installation
1. Download all files to your project directory
2. Open `portfolio.html` in your web browser
3. Customize the content with your information

### Customization

#### Personal Information
Edit the following in `portfolio.html`:
- Name and title in the hero section
- About section content
- Contact information
- Social media links

#### Projects
Update the projects section with your actual projects:
- Project titles and descriptions
- Technology stacks
- GitHub repository links
- Live demo URLs
- Project images

#### Skills
Modify the skills section in `portfolio.js`:
```javascript
const skills = [
    { name: 'Python', percentage: 85 },
    { name: 'JavaScript', percentage: 75 },
    { name: 'HTML/CSS', percentage: 90 },
    { name: 'React', percentage: 70 },
    { name: 'C Programming', percentage: 80 }
];
```

#### Styling
Customize colors and fonts in `portfolio.css`:
- Primary color: `#4f46e5`
- Secondary color: `#7c3aed`
- Font family: `'Inter', sans-serif`

## 🚀 Deployment

### GitHub Pages
1. Push files to a GitHub repository
2. Enable GitHub Pages in repository settings
3. Select source branch
4. Access your site at `username.github.io/repository-name`

### Netlify
1. Drag and drop your project folder to Netlify
2. Configure custom domain (optional)
3. Enable form handling for contact form

### Vercel
1. Connect your GitHub repository
2. Configure build settings
3. Deploy automatically on push
